# Mental Healthcare AI

A small, self-contained mental-health awareness demo built as a single HTML page. No installation, build step, or API key is required.

## Run it locally

Download or clone this repository, then open `index.html` in a web browser. It redirects to the demo page, `mental-health-awareness (1).html`.

## Publish it as a website with GitHub Pages

The repository needs GitHub Pages enabled before it has a public website URL:

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Set the branch to **`main`** and the folder to **`/(root)`**, then click **Save**.
4. Wait for GitHub Pages to finish deploying. The site will be at:
   **https://sarthakmane57.github.io/mental-healthcare-ai/**

The repository's root `index.html` forwards visitors to the demo page. You can also open the demo directly at [mental-health-awareness (1).html](https://sarthakmane57.github.io/mental-healthcare-ai/mental-health-awareness%20(1).html).

## About the demo

The chat responses are prewritten and selected by simple keyword matching; the page does not call an AI service. It is an informational demo, not a diagnosis or a substitute for professional care. If you may be in immediate danger, contact your local emergency services or a crisis support service in your area.
